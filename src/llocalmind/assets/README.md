# Desktop artwork and fonts

- `logo.png`: the approved LLocalMind LL/book emblem with the faded M,
  generated during the project's design session. Kept as a transparent PNG.
- `fonts/Sora-600.ttf`: static semibold instance of Sora.
- `fonts/Manrope-400.ttf`, `fonts/Manrope-600.ttf`: static regular/semibold
  instances of Manrope. Static instances avoid inconsistent variable-font
  weight selection across Qt platforms.

Font sources: https://github.com/google/fonts/tree/main/ofl/sora and
https://github.com/google/fonts/tree/main/ofl/manrope . Distributed under the
SIL Open Font License; original notices/licenses are included alongside the
fonts. They are bundled locally: the app makes no font-download requests.
